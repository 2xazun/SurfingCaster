# SurfingCaster

실시간 해양 정보 기반 서핑 및 해양 레저 탐색 서비스

## 1. 프로젝트 소개

SurfingCaster는 해양 관측 정보를 활용하여
사용자가 서핑 및 해양 레저 장소를 탐색하고
현재 해양 상태를 확인할 수 있도록 돕는 서비스입니다.

## 2. 개발 환경

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Node.js+Express
- MySQL
- Kakao Map API
- 기상청 및 국립해양조사원 Open API

## 3. 실행 방법

### 1) 프로젝트 다운로드

GitHub 저장소를 Clone하거나 ZIP 파일로 다운로드합니다.

### 2) 데이터베이스 설정

- MySQL 서버를 실행합니다.
- 데이터베이스를 생성합니다.
- 제공된 SQL 파일을 실행하여 테이블과 초기 데이터를 생성합니다.

### 3) API 및 DB 접속 정보 설정

- Kakao Map API 키를 설정합니다.
- 공공데이터 API 인증키를 설정합니다.
- DB 접속 정보를 설정합니다.

### 4) 백엔드 서버 실행

- 백엔드 프로젝트 폴더로 이동합니다.
- 필요한 패키지를 설치합니다.
- Node.js 서버를 실행합니다.

### 5) 프론트엔드 실행

- VS Code에서 프로젝트 폴더를 엽니다.
- Live Server 확장 프로그램을 설치합니다.
- index.html 파일을 우클릭합니다.
- Open with Live Server를 선택합니다.
- 브라우저에서 실행된 페이지를 확인합니다.
